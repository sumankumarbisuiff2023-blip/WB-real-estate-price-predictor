### \# 🏠 West Bengal Real Estate Price Predictor

### 

### An end-to-end Machine Learning web application designed to predict residential property prices in West Bengal.

### 

### \- \*\*Dataset\*\*: `readyflat.csv` (400 records)

### \- \*\*Model\*\*: scikit-learn Pipeline (`OneHotEncoder` + `LinearRegression`) ($R^2 \\approx 0.70$)

### \- \*\*Frontend\*\*: Streamlit
